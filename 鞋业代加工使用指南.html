三、核心档案设计

1. 工厂指令单号（自定义字段）

自定义字段 custom_factory_order_no 已添加到以下单据，实现按指令单跨环节追溯：

  • 销售订单、生产计划、工单、物料申请、采购订单、采购收货、采购发票
  • 委外订单、委外发料/收货、库存单据、Job Card 报工单

在列表页可按 custom_factory_order_no 筛选，一个指令单号即可穿透查看全部关联单据。

2. 款号 / 尺码 / 颜色（变体管理）

层级编码示例说明
款号（模板物料）FG-A001款号 A001，启用变体，属性：尺码（40–43）、颜色（BK 黑）
成品变体FG-A001-41-BKA001 款 / 41 码 / 黑色，对外销售与入成品仓的最小单元
半成品SF-A001A001 款帮面（车缝完成后）
材料M-FAB-001 等面料 / 里布 / 大底 / 中底 / 五金扣件 / 胶水 / 针车线
委外服务SVC-STI车缝加工服务（12 元/双）

3. BOM（物料清单）

BOM结构
帮面半成品 BOMSF-A001 = 面料 0.5 码/双 + 里布 0.35 码/双 + 五金扣件 12 个/双 + 针车线 0.2 个/双
成品 BOM（多层）FG-A001-41-BK = 帮面 SF-A001 1 双 + 大底 1 双 + 中底 1 双 + 胶水 0.01 桶/双
委外 BOMSVC-STI 服务 BOM，供应物料 = 帮面四件材料（发料给委外厂）

4. 仓库布局

仓库用途
材料仓 - 奥登科采购材料收货存放；委外发料、工单领料源头
委外供应商仓 - 奥登科发料给委外厂时材料的在途/委外占用量
半成品仓 - 奥登科委外收货的帮面半成品存放
在制品 - 奥登科（WIP）工单领料后的在制材料
成品仓 - 奥登科完工成品入库

5. 条码（扫码出入库）

所有交易物料已配置 EAN-13 条码（如面料 6901234500011、帮面 6901234510002、成品 41 码 6901234520418）。在采购收货单、库存单据、委外收货单的「扫描条码」输入框扫码即可自动带出物料行，配合扫码枪/PDA 即可实现仓库扫描出入库。

四、日常操作 SOP（新指令单从零到对账）

第 1 步 · 接单（业务员）

  1. 【销售订单】新建：客户、款号变体成品、数量、价格；填写工厂指令单号（如 FO-2026-002）。
  2. 提交后系统自动锁定该指令单的全部下游追溯。

第 2 步 · 计划与 MRP（计划员）

  1. 【生产计划】从销售订单拉入需求，或手动输入款号+数量，填指令单号。
  2. 点击「创建物料申请（MRP）」→ 系统按 BOM 展开计算材料净需求（已扣半成品/在库量）。
  3. 物料申请提交后，按供应商分组「创建采购订单」。
  4. 同时生成工单（Work Order）。

第 3 步 · 采购与材料入库（采购 + 仓管）

  1. 提交采购订单（材料 PO、委外加工费 PO）。
  2. 供应商送货，仓管在【采购收货单】扫描条码收货入材料仓并提交。

第 4 步 · 委外加工（发料 → 收帮面）

  1. 从委外 PO 生成【委外订单 SCO】，确认供应商、服务单价、供应商仓库。
  2. SCO 提交后点击「发料给分包商」→ 生成发料单（材料仓 → 委外供应商仓），提交。
  3. 委外厂交帮面回厂：【委外收货单】录入/扫码 2000 双帮面 → 半成品仓，提交。
  4. 系统自动按 BOM 倒冲扣减委外供应商仓材料（本例 4 种材料全部消耗清零）。

第 5 步 · 成型生产与成品入库（车间 + 仓管）

  1. 工单（已由生产计划生成）→「开始」工单。
  2. 工单页点击「物料转移」生成领料单：帮面（半成品仓）+ 大底/中底/胶水（材料仓）→ 在制品仓，提交。
  3. 【MES 报工】打开该工单的 Job Card（工序：成型 / 工位：成型车间A线），录入员工、起止时间、完成数量，提交。
  4. 工单页点击「完工」生成完工入库单：成品 FG-A001-41-BK × 2000 → 成品仓，提交。工单自动变 Completed。

第 6 步 · 财务应付与厂商对账（财务）

  1. 对每张采购收货单「创建采购发票」（委外加工费由委外收货单自动生成收货单后开票）。
  2. 提交发票形成应付（债权人科目），核对品项/数量/单价与 PO 一致。
  3. 【付款单 Payment Entry】选供应商，勾选发票，现金/银行付款，提交 → 发票状态变 Paid。
  4. 厂商对账：报表「应付账款 / 供应商账簿」按供应商查看开票、付款、余额；本次验证三家供应商余额均为 0.00：
    供应商开票已付余额
    泉州兴发纺织有限公司30,600.0030,600.000.00
    东莞宏力鞋材有限公司55,580.0055,580.000.00

第 7 步 · 出货（可选，外贸交货）

  1. 销售订单「创建交货单」→ 成品仓扫码发货 → 提交。
  2. 「创建销售发票」向客户开票收款（应收流程与应付对称）。
