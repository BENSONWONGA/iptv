一、3 分钟入门：只用懂 3 件事

① 系统里一切都是「单据」。接一张客户订单是一张单，买一批面料是一张单，把鞋从材料仓搬到成品仓也是一张单。干活 = 填单 + 提交。

② 单据只有三种状态，规则很简单：

状态意思能不能改
草稿还没生效，只是记了个底稿能改、能删
已提交正式生效：库存、欠款、生产计划从此刻开始计算锁死，不能再改；填错了走「取消」
已取消作废（保留痕迹，方便对账追查）—

③ 表单里两个小规矩：带 * 的必须填；选客户/物料/仓库的输入框，直接打字（如"外贸"）会自动弹出候选，点一个即可，不用手输全名。

每个列表页右上角都有一个橙色按钮 ＋ 新建×××，所有新业务都从这里开始。每张单据旁的 后台 按钮会打开原版系统的同一张单——不影响数据，老板可以放心随便点、随便看。

二、每天开机 3 步

  1. 登录：打开系统地址，登录页会自动填好令牌，直接点 登 录 按钮即可。
  2. 看工作台：进来先看顶部三个数字 —— 进行中指令单（手上还有几单在生产）、待付货款（还欠供应商多少钱）、成品仓库存（成品还剩多少双）。中间横条是最近一单「接单 → 付款」的全流程进度。
  3. 处理待办：「待办事项」卡片会列出还没提交的销售订单，点 去处理 检查无误后提交——不提交的订单不进入排产算料，等于白接。

四、分岗位操作指引

4.1 接单员：新建指令单（最常用的操作）

  1. 点导航 指令单中心，进入订单列表。
  2. 点右上角橙色 ＋ 新建指令单，右侧弹出表单。
  3. 填客户（打字选）、厂令号（自己编的生产单号，如 FO-2608-01）、交货日期。
  4. 填鞋款物料（打字选编码）、数量（双），单价可填可不填。
  5. 点 保存并提交。绿色提示出现单号（如 SAL-ORD-2026-00012）即生效。
  6. 提交后这单自动出现在工作台进度条和MRP 算料的候选里，点列表行的「链路」可随时看它走到哪一步。
注意：填错内容先别慌——单号旁边有 取消 按钮，作废后重新建一张就行，不要在已提交的单上硬改。

4.2 生管 / 采购：MRP 算料（很多人问"MRP 在哪"——在「物料管理」页）

  1. 点导航 物料管理，右上角有三个按钮：＋ 新建物料、＋ 新建 BOM、⚙ MRP 采购申请。
  2. 点 ⚙ MRP 采购申请，先选择指令单（哪张订单要算料）。
  3. 点 ⚙ 计算净需求——系统自动展开这款鞋的 BOM，扣除材料仓现有库存，算出真正要买多少。
  4. 确认明细无误后点提交，生成采购申请（单号 MAT-MR-2026-000xx）。
  5. 再到 采购管理 页，点 ＋ 新建采购单 向面料 / 底料供应商下单；供应商送货后在同一页做收货，材料自动进材料仓。
要算料先得有 BOM（一双鞋用多少料）：物料管理页点 ＋ 新建 BOM → 选成品款号 → 逐行添加组件物料和用量 → 提交。BOM 建一次，以后算料 / 生产 / 委外全用它。

4.3 仓库 / 车间：扫码出入库（最好用的功能）

  1. 点导航 扫码出入库。
  2. 用扫码枪扫物料条码（或手动输入编码后按回车）。
  3. 屏幕显示物料信息即已识别。然后选三样：从哪个仓 → 到哪个仓、数量。
  4. （可选）填工厂指令单号，方便日后按单追溯。
  5. 点 提交出入库，立刻生成库存调拨单（MAT-STE-2026-000xx）并生效，下方日志栏会记录每次操作。
业务场景选仓方向
发料给委外厂材料仓 → 委外仓
车间领料投产半成品仓 → 在制品
成品完工移仓在制品 → 成品仓
其他内部调拨按实际从哪到哪选

想查某仓现存多少料：去 仓库管理 页看库存表，或在工作台「库存概览」卡看各仓总数。

4.4 委外跟单：一步开委外

  1. 点导航 委外加工，点 ＋ 新建委外单。
  2. 填加工厂供应商、加工服务项目（如"针车加工费"）、产出成品/半成品款号、数量、加工单价。
  3. 提交后系统自动连开两张单：委外采购单 + 委外加工单（都会自动提交生效），不用自己再去后台配。
  4. 发料给加工厂走 4.3 扫码（材料仓 → 委外仓）；加工品回来在委外加工页做委外收货。

4.5 生产 / 厂长：工单与报工

  1. 点导航 生产制造，能看到生产计划和生产工单进度（已投产多少双、完成多少双）。
  2. 裁断 / 针车 / 成型每道工序完工后，在对应工单里报工登记数量。
  3. 整单完工后做完工入库，成品进入成品仓，工作台「成品仓库存」数字随之更新。

4.6 财务 / 老板：付款与对账

  1. 付供应商货款 / 加工费：点 应付对账 → ＋ 登记付款 → 选供应商、填金额、写上摘要（如"10 月针车加工费"）→ 提交，财务分录自动生成。
  2. 每家供应商的欠款余额直接显示在应付对账列表里，付款后实时减少。
  3. 想看某张客户订单从头到尾的全链路（接单→采购→委外→生产→出货→收款）：点 流程图中心，按厂令号穿透查每一步对应的单据。

五、常见问题

Q：找不到我的单据了？　在对应页面顶部搜索框输入单号片段（如 00012）回车即可。单号规则见附录。

Q：提交错了想改？　已提交的单不能改，点 取消 作废，重新建一张正确的。系统保留作废痕迹，账目可追溯。

Q：提示"无法读取 / 没权限"？　这是权限保护（例如门户账号看不到固定资产），找管理员开通对应权限即可，不是系统坏了。

Q：页面一直转圈或白屏？　刷新页面；还不行就退出重新登录。你看到的数据都在服务器上，不会丢。

Q：还想要打印、修订等高级操作？　点单据旁的 后台 按钮进入原版系统做，两边是同一份数据，随便切换。
